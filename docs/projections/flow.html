What this view is

Chapter 4 says nobody needs to read the IR: a projection renders a node as a flow, showing which steps touch hardware, which are pure computation, where each guarantee is proved and which intent it serves. This is that view, for every function of the cache. Each step is one statement of the IR in plain notation; its colour says what kind of step it is; under it are the proof obligations discharged at that step, with the clause each serves. Hashes, addresses and versions are left out.

Obligations are placed on the step they are about by matching what they name (a callee, a region, a loop, a lock) in program order; those that name nothing in particular are listed for the function as a whole.
