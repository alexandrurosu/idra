What this view is

Chapter 3 lists schemas among the projections compiled from the graph, and Chapter 6 replaces the operating system's memory management with regions and ownership in the program. This is the cache's memory as the program declares it: every region, how large it is, who owns it, and the size classes that the declared workload produces. Nothing in it was laid out by hand: the regions are the program's, and the classes come from the intent's workload declaration (cache/layout.py).

Size classes, from the declared workload

Each band the intent declares becomes a class of fixed-size slots, with the band's share of the item memory. The store is split by key into 8 shards, each laid out alike: one shard holds 44,323 items in 100,238,312 bytes and 131,072 table cells (16,384 buckets of 8). A regenerated declaration changes only this table, and the whole program is proved again for it (C-9).
